# Three Months With You — A Digital Love Letter for My Boo

A romantic, responsive digital love letter celebrating our **3rd Monthsary**, crafted with HTML5, CSS3, and Vanilla JavaScript.

## Files for GitHub Pages Deployment

All required files sit cleanly at the root so you can upload them directly to a GitHub repository without nested folder issues:

```text
monthsary-website/
├── index.html
├── style.css
├── script.js
├── About You.mp3
└── README.md
```

- **Flowers**: Embedded directly as inline animated SVGs inside `index.html` (no external image requests).
- **Fonts**: Loaded via Google Fonts (`Cormorant Garamond`, `Dancing Script`, `Lora`) over HTTPS with system serif/cursive fallbacks.
- **Music**: `About You.mp3` sits right next to `index.html` and starts playing when **"There's Something I Want to Tell You"** is clicked.
